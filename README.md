# 現金流配息計畫

貸款還款與季度配息現金流試算工具。

## 功能

- 試算貸款本金、年利率、期數與每月月付金
- 模擬三檔季度配息標的的配置比例
- 查看每月配息、每月還款與現金流餘額
- 支援 GitHub Pages 靜態部署

## GitHub Pages

將本專案上傳至 GitHub 後，進入 **Settings → Pages**，在 **Build and deployment** 選擇：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後即可取得 GitHub Pages 網址。

> 本工具僅供個人財務規劃與教育用途，不構成投資、借貸或稅務建議。殖利率、配息與股價均可能變動。
