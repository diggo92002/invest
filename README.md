# 現金流配息計畫

貸款還款與季度配息現金流試算工具。

## 功能

- 試算貸款本金、年利率、期數與每月月付金
- 模擬三檔季度配息標的的配置比例
- 候選名單保留月配與季配息 ETF：0056、00878、00919、00713、00918、00929（月配）、00915；預設前三檔 34%、33%、33%，其餘 0%
- 查看每月配息、每月還款與現金流餘額
- 支援 GitHub Pages 靜態部署

## 殖利率資料更新

Windows 在本資料夾執行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`，再開啟 http://127.0.0.1:8787 。啟動器會使用已安裝的 Node.js 或 VS Code 內附執行環境；也可直接使用 Node.js 20 以上執行 `node server.mjs`。

- 開頁自動查詢，頁面開啟時每小時查詢一次，也可按「更新殖利率」。資料為證交所每日收盤資料，並非盤中即時報價。
- 個股採證交所 BWIBBU_ALL 公布殖利率；ETF 以近一年除息金額總和除以資料日收盤價計算，不以單次配息年化。每檔標示資料日期；查詢時間與資料日期分開顯示。
- 成功結果保存在瀏覽器；部分或全部連線失敗時保留舊資料或內建試算值，清楚標示來源狀態。更新不會重設配置。
- 本機服務只連線固定證交所端點，處理瀏覽器跨網域限制，成功回應快取一小時。公司代理伺服器仍可能阻擋對外查詢。
- 直接開啟 HTML 或部署 GitHub Pages 時改用瀏覽器直接連證交所，是否成功取決於證交所的跨網域設定。若被擋，請使用上述本機服務；GitHub Pages 本身不執行此服務。
- 入帳月份仍為原有模擬設定，不會同步最新配息行事曆；年配息按設定月份數分配，全年總額與年配息試算一致。

驗證：`node --test market-data.test.mjs`。

## GitHub Pages

將本專案上傳至 GitHub 後，進入 **Settings → Pages**，在 **Build and deployment** 選擇：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後即可取得 GitHub Pages 網址。

> 本工具僅供個人財務規劃與教育用途，不構成投資、借貸或稅務建議。殖利率、配息與股價均可能變動。
