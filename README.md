# 現金流配息計畫

貸款還款與季度配息現金流試算工具。

- 線上版：https://diggo92002.github.io/invest/
- 操作方式請看 [使用說明](使用說明.md)；改了什麼請看 [修改履歷](修改履歷.md)。

## 功能

- 試算貸款本金、年利率、期數與每月月付金；本金以萬元輸入（600 代表 600 萬元），原先儲存的金額會自動換算
- 模擬三檔季度配息標的的配置比例
- 候選名單保留月配與季配息 ETF：0056、00878、00919、00713、00918、00929（月配）、00915；預設前三檔 34%、33%、33%，其餘 0%
- 查看每月配息、每月還款與現金流餘額
- 支援 GitHub Pages 靜態部署

## 殖利率資料更新

- 新增標的只需填股票代號，會自動取得名稱、殖利率及歷史現金發放月份。ETF 月份來自證交所收益分配資料；個股月份來自 FinMind TaiwanStockDividend。依最近一次發放日前一年的紀錄推算，未來仍以公告為準。查詢失敗或缺少發放日會保留代號供重試，不套用預設月份。

- 開頁自動查詢，頁面開啟時每小時查詢一次，也可按「更新殖利率」。資料為證交所每日收盤資料，並非盤中即時報價。
- 個股採證交所 BWIBBU_d 公布殖利率；ETF 以近一年除息金額總和除以資料日收盤價（證交所 STOCK_DAY_ALL）計算，不以單次配息年化。每檔標示資料日期；查詢時間與資料日期分開顯示。
- 成功結果保存在瀏覽器；部分或全部連線失敗時保留舊資料或內建試算值，清楚標示來源狀態。更新不會重設配置。
- 純靜態網頁，瀏覽器直接連證交所 www.twse.com.tw/rwd 端點與 FinMind（皆允許跨網域），GitHub Pages 或直接開啟 HTML 都能自動更新，不需後端服務。openapi.twse.com.tw 不允許跨網域，因此不使用。公司網路的代理伺服器仍可能阻擋對外查詢。
- 入帳月份仍為原有模擬設定，不會同步最新配息行事曆；年配息按設定月份數分配，全年總額與年配息試算一致。

驗證：`node --test market-data.test.mjs`。

## GitHub Pages

將本專案上傳至 GitHub 後，進入 **Settings → Pages**，在 **Build and deployment** 選擇：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

儲存後即可取得 GitHub Pages 網址。
